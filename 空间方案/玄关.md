# 玄关

这项是什么：入户区域，重点是鞋柜、照明、开关和动线。两辆公路车可以外露，若现场玄关或入户附近有合适靠墙位，可优先作为公路车落位候选，但不能挡入户门和主通道。

谁来做：

- 你：确认鞋柜和开关位置。
- 工长/电工/油工：基础硬装。
- 定制商家：鞋柜。

预算卡法：

- 只做基础鞋柜。
- 不做复杂入户造型墙。
- 不为公路车做高价展示柜，先按靠墙靠边外露处理。

具体步骤：

1. 入户门打开后确认鞋柜位置。
2. 玄关灯用基础吸顶灯或小灯。
3. 鞋柜不要挡门。
4. 墙面暖白即可。
5. 如果公路车放玄关附近，现场用胶带画出车身范围，确认不挡门、不挡鞋柜、不挡通道。

你要问的话：

- 鞋柜深度够吗？
- 入户开关顺手吗？
- 门打开会不会撞柜子？
- 两辆公路车如果靠玄关外露，会不会挡门和通道？

可复制话术：

```text
玄关只做基础鞋柜和基础照明，不做造型墙和灯带。两辆公路车可以外露，如果玄关或入户附近有靠墙位，请现场帮我确认不挡入户门、不挡鞋柜、不挡主通道。鞋柜单独报价，不做高价公路车展示柜。
```

报价单必须写清：

- 鞋柜尺寸。
- 公路车靠墙外露范围如放玄关，需要现场标记。
- 灯具点位。
- 开关点位。
- 墙面处理。

验收：

- 入户门正常开关。
- 鞋柜开关顺畅。
- 开关顺手。
- 如放公路车，车身不挡门、不挡主通道。

不要做：

- 不做玄关背景墙。
- 不做灯带。
- 不做复杂开放格。

付款/确认节点：

- 鞋柜安装验收后付尾款。
