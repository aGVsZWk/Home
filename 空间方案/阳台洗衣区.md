# 阳台洗衣区

这项是什么：阳台作为洗衣区，预留洗衣机、烘干机和分桶洗衣机，但不做洗手台。重点是水、电、排水、防水、检修和尽量少放东西。

谁来做：

- 你：确认洗衣机、烘干机、分桶洗衣机预留位置。
- 工长/水电师傅：上下水、插座、地漏。
- 安装师傅：洗衣机安装。

预算卡法：

- 阳台只做基础地砖、洗衣机水电。
- 洗衣柜、阳台柜、烘干机柜后补。
- 洗烘套装本体和分桶洗衣机本体都可后补，但水电和尺寸先留。
- 不做阳台洗手台，不把阳台塞满。

具体步骤：

1. 开工交底时确认洗衣机、烘干机、分桶洗衣机都按阳台预留。
2. 留洗衣机进水、排水、插座，并确认分桶洗衣机是否共用排水或单独排水。
3. 如果确定买海尔云溪5.0洗烘套或小天鹅小乌梅5.0套装，先确认叠放还是并排，再留两台机器的电源和检修空间。
4. 如果暂时不买套装，至少把阳台尺寸和电源条件按“未来可加烘干机”考虑。
5. 插座不要太靠近明水，必要时加防溅。
6. 阳台地面贴防滑砖。
7. 不做洗手台，优先留空和检修空间。

你要问的话：

- 阳台有没有地漏？
- 洗衣机排水怎么走？
- 插座位置安全吗？
- 洗衣柜是否后补？
- 洗烘套装是叠放还是并排，插座要几个？
- 分桶洗衣机放哪里，排水怎么走？
- 不做洗手台后，阳台空余空间能否保留？

可复制话术：

```text
洗衣区放阳台，预留洗衣机、烘干机和一台分桶洗衣机洗内衣袜子，不做阳台洗手台，阳台尽量少放东西并保留检修空间。我现在在海尔云溪5.0洗烘套和小天鹅小乌梅5.0套装里二选一，请先按最终套装尺寸帮我核对阳台位置、进水、排水、地漏、插座数量和检修空间。如果预算后面不够，洗烘套装本体和分桶洗衣机本体可以后买，但水电和尺寸预留不要漏。
```

报价单必须写清：

- 洗衣机水位。
- 排水改造。
- 插座点位。
- 地漏处理。
- 如预留洗烘套装，插座数量、叠放/并排空间是否满足。
- 分桶洗衣机插座和排水预留。
- 阳台地砖面积。
- 洗衣柜是否不包含。
- 阳台洗手台是否明确不包含。

验收：

- 洗衣机进水可用。
- 分桶洗衣机预留不和洗烘套装打架。
- 排水顺。
- 地漏不反味。
- 插座通电且位置安全。

不要做：

- 没定尺寸前不盲目买洗烘套装。
- 不默认阳台柜。
- 不做高端洗衣柜。
- 不做阳台洗手台。
- 不封死检修位置。

付款/确认节点：

- 水电验收时确认阳台洗衣位。
- 洗衣机安装试水后确认。
