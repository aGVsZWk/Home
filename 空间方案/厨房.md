# 厨房

这项是什么：你家厨房按“开放式大厨房 + 导台/吧台 + 餐桌”作为最高优先级来做。你喜欢做饭，厨房要好用、够大、多电器高频使用；但仍然按极限省钱思路，先把布局、水电、台面和预留做好，不把所有电器一次买齐。

谁来做：

- 你：确认厨房功能边界和预算。
- 工长/水电师傅：按橱柜水电建议预留。
- 橱柜商家：设计橱柜和台面。
- 电器/水槽商家：提供尺寸和安装。
- 物业/燃气相关方：开工前确认开放式厨房、燃气、烟道、拆改和验收限制。

预算卡法：

- 橱柜8000-15000。
- 厨房砖和吊顶并入瓦工、瓷砖、吊顶预算。
- 现在不默认购买净水器、蒸烤箱等全部升级电器，但洗碗机、冰箱、烟灶、水槽、导台/吧台和高频小电器点位要先预留。
- 开放式厨房是硬目标，但不能用违法拆改、乱动燃气或破坏承重来实现；如果现场存在硬性限制，必须单独停下来重新决策。

分区建议：

- 开放边界：优先扩大厨房和餐厅的连接感，导台/吧台与餐桌形成备菜、上菜、吃饭连续动线。
- 灶台墙面：必须贴砖，建议贴到吊顶底，油污好擦。
- 水槽墙面：必须贴砖，建议贴到吊顶底，防水溅。
- 操作台后墙：建议贴砖，至少台面以上600毫米到吊顶底。
- 远离水火的门边小墙：如果不容易溅水油，可以刷耐擦洗乳胶漆，但厨房潮气油烟重，预算允许更建议墙面全砖。
- 地面：贴防滑地砖。
- 小电器区：电饭煲、空气炸锅、咖啡机、破壁机等高频设备不要全挤在水槽边，插座要分散且远离明水。
- 餐桌区：餐桌附近留插座，方便火锅、电脑临时使用或后期小电器。

买现在用的：

- 烟机。
- 灶具。
- 水槽。
- 龙头。
- 基础橱柜。
- 厨房基础插座。
- 地漏如原厨房有地漏。
- 导台/吧台或餐桌的尺寸关系，至少先定布局和点位。

只预留以后用的：

- 洗碗机位置和插座。
- 净水器插座。
- 蒸烤箱或小厨电插座。
- 冰箱独立插座。
- 导台/吧台插座。
- 餐桌旁插座。

具体步骤：

1. 开工前先核验开放式厨房是否受物业、燃气、承重墙、烟道、门洞和预算限制。
2. 找橱柜商家按开放式厨房出初步水电建议。
3. 水电定位时确认烟机、灶具、水槽、冰箱、导台/吧台、餐桌、小厨电位置。
4. 洗碗机、净水器、蒸烤箱可只预留，不默认购买。
5. 贴砖前确认厨房墙地砖数量。
6. 瓦工后橱柜复尺。
7. 橱柜安装后再装水槽、龙头、烟机灶具。

你要问的话：

- 厨房哪些墙必须贴砖？
- 开放式厨房涉及的墙体、门洞、燃气和烟道限制有没有确认？
- 橱柜商家能否给水电点位图？
- 洗碗机预留需要多宽？
- 净水器插座放哪里不会被水淋？
- 导台/吧台和餐桌之间的通道够不够？
- 高频小电器插座够不够，是否远离明水？

可复制话术：

```text
厨房按开放式大厨房做，这是最高优先级。请先核验物业、燃气、承重墙、烟道、门洞和预算，再按导台/吧台加餐桌、高频做饭、多电器使用来出水电和橱柜建议。现在先买烟机、灶具、水槽、龙头和基础橱柜；洗碗机、净水器、蒸烤箱可以只预留位置和插座。灶台、水槽、操作台周边请按好清洁、防潮处理，墙砖范围和高度请写清。
```

报价单必须写清：

- 厨房墙砖、地砖面积。
- 厨房水电点位。
- 开放式厨房拆改、门洞、燃气、烟道、排烟和验收风险。
- 橱柜地柜、吊柜、台面。
- 导台/吧台是否包含，和餐桌关系是否单独说明。
- 烟机灶具安装是否涉及开孔。
- 水槽龙头安装是否包含。
- 预留升级位是否只留点位，不含购买电器。

验收：

- 烟机、灶具、水槽位置合理。
- 导台/吧台、餐桌和厨房通道不互相打架。
- 水槽不漏水。
- 厨房插座够用且远离明水。
- 预留插座没有被柜体封死。
- 墙砖好擦，地砖防滑。

不要做：

- 不买高柜。
- 不买洗碗机、净水器、蒸烤箱作为默认项。
- 不为了开放式厨房违法拆承重墙、乱动燃气表或破坏烟道。
- 不为了导台/吧台做复杂造型和高价石材。
- 不大改卫生间和厨房主上下水，除非开放式厨房可行性确认后确有必要且单独报价。

付款/确认节点：

- 厨房水电点位确认后做水电。
- 瓦工验收后橱柜复尺。
- 橱柜安装验收后付尾款。
