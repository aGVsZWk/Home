# 主卫

这项是什么：主卧附近卫生间，完整保留，带淋浴、马桶、浴室柜。

谁来做：

- 你：确认洁具尺寸和基础配置。
- 工长/防水/瓦工：防水、贴砖、坡度。
- 洁具商家：安装马桶、花洒、浴室柜。

预算卡法：

- 主卫不做豪华，只做完整基础。
- 玻璃淋浴房不默认做，优先浴帘或简单挡水。

分区建议：

- 淋浴区墙面：必须贴砖，至少1.8米，建议到吊顶底。
- 淋浴区地面：必须防滑砖，坡向地漏。
- 马桶区墙面：靠近淋浴或水汽重时建议贴砖到1.2米以上，预算允许可到吊顶底。
- 台盆区墙面：台面以上至少贴到1.2米，防溅水；镜柜周边可贴砖或刷耐擦洗漆。
- 干区墙面：如果确实远离淋浴，可刷防潮耐擦洗乳胶漆，但要避免直接淋水。

具体步骤：

1. 水电前确认马桶坑距、花洒位置、浴室柜宽度。
2. 防水做足淋浴区高度。
3. 闭水通过后贴砖。
4. 地面坡度验收通过后再装洁具。
5. 洁具安装后试水。

你要问的话：

- 主卫淋浴区墙面做到多高？
- 地漏位置和坡度怎么做？
- 马桶坑距是多少？
- 浴室柜尺寸是否会挡门？

可复制话术：

```text
主卫要完整保留并带淋浴。马桶位尽量不动，淋浴区防水和墙砖做到足够高度，地面要有坡度流向地漏。预算紧，淋浴房先不默认做，可以先浴帘或简单挡水。请把墙砖高度、防水高度、闭水、地漏坡度和洁具安装写清。
```

报价单必须写清：

- 防水面积和高度。
- 墙砖、地砖面积。
- 花洒、马桶、浴室柜型号和安装费。
- 地漏、角阀、软管是否包含。
- 挡水条或浴帘杆是否包含。

验收：

- 闭水通过。
- 淋浴排水顺。
- 马桶不漏水。
- 花洒冷热水正常。
- 浴室柜排水正常。

不要做：

- 不大移马桶位。
- 不默认玻璃淋浴房。
- 不做壁龛。
- 不做智能马桶默认项。

付款/确认节点：

- 防水闭水通过后付防水节点。
- 洁具安装试水通过后付安装尾款。
