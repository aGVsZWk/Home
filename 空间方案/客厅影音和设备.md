# 客厅影音、公路车和运动设备

这项是什么：客厅仍然是公共活动和影音空间，同时要容纳85寸电视影音预留、两辆公路车候选位和现有椭圆机。原则是靠墙靠边、少挡通道、先外露，不为了好看做高价柜。

谁来做：

- 你：确认电视墙、沙发、椭圆机、公路车大概位置。
- 工长/电工：电视墙、后环绕、低音炮、设备插座和线管预留。
- 家具/安装商家：电视、回音壁、支架、沙发等后期安装。

预算卡法：

- 85寸电视和三星Q990F本体可后补，硬装只预留电源、网口、线管和后环绕电源。
- 公路车和椭圆机是现有物品，必须有位置，但可以外露。
- 不做电视背景墙，不做电视背景柜，不做公路车展示柜。

具体步骤：

1. 量电视墙宽度和观看距离，确认85寸电视是否合适。
2. 电视墙预留电源、网口、HDMI/eARC线管，插座不要被电视或电视柜挡死。
3. 回音壁在电视下方预留位置；低音炮预留客厅角落或电视柜旁电源。
4. 后环绕在沙发后方或两侧预留电源，避免后期拉明线。
5. 椭圆机优先放客厅靠边或阳台附近，不挡阳台门、窗帘和主通道。
6. 两辆公路车可在玄关、客厅靠墙或书房靠墙之间现场择优，先外露，不做隐藏柜。

你要问的话：

- 85寸电视墙宽和观看距离够不够？
- 后环绕电源放沙发后还是侧墙？
- 椭圆机放下后会不会挡通道、窗帘或阳台门？
- 公路车靠墙外露会不会挡门、挡柜门、挡老人通行？

可复制话术：

```text
客厅按85寸电视和三星Q990F影音预留，但电视和影音本体可以后买。请帮我预留电视墙电源、网口、HDMI/eARC线管、回音壁位置、低音炮电源和后环绕电源。两辆公路车和椭圆机是现有物品，需要先入住就能放，可以外露靠墙靠边，不做展示柜和隐藏柜。请现场帮我确认它们不挡入户门、阳台门、柜门和主通道。
```

报价单必须写清：

- 电视墙电源、网口、线管数量。
- 后环绕电源点位。
- 低音炮电源点位。
- 是否涉及电视壁挂加固或预埋管。
- 公路车和椭圆机只是落位，不包含定制柜。

验收：

- 电视墙插座和线管可用。
- 后环绕和低音炮电源通电。
- 椭圆机、公路车落位不挡主通道。
- 没有为了影音和车额外做背景墙或高价柜。

不要做：

- 不做电视背景墙。
- 不做满墙电视柜。
- 不为公路车做展示柜。
- 不为了运动设备牺牲开放式厨房和独立书房。

付款/确认节点：

- 水电验收时确认影音和后环绕点位。
- 家电安装后再验收电视、回音壁和后环绕。
