# 宠物和清洁设备位

这项是什么：两只猫和清洁设备需要提前留位置。重点不是把设备藏起来，而是有电源、好清洁、少挡路、少反味。

谁来做：

- 你：确认猫砂盆、喂食机、饮水机、扫地机器人、洗地机大概位置。
- 工长/电工/水电师傅：预留插座，评估扫地机器人上下水可行性。
- 设备商家：后期安装扫地机器人上下水或清洁设备。

预算卡法：

- 猫设备是入住刚需，位置和插座必须先留。
- 扫地机器人和洗地机都保留位置；扫地机器人上下水可后补。
- 不做高价宠物隐藏柜，不为了藏猫砂盆牺牲通风和清洁。

默认落位原则：

- 猫砂盆优先靠次卫、阳台附近或其他易清洁、可通风的位置。
- 自动喂食机和饮水机靠墙放，附近留插座，避开主通道和门后。
- 扫地机器人靠近可上下水位置更好，但预算紧时先留普通停靠位和插座。
- 洗地机靠近卫生间、阳台或清洁工具区，方便倒污水、充电和晾干。

具体步骤：

1. 开工交底时用胶带画出猫砂盆、喂食机、饮水机、扫地机器人、洗地机范围。
2. 每个自动设备附近至少考虑1个插座，猫砂盆和饮水机插座注意防水和防咬线。
3. 如果扫地机器人上下水要做，先问清是否需要靠近水源、排水、地柜或墙体开孔。
4. 如果预算紧，扫地机器人上下水后补，先保留停靠空间、普通插座和不挡门的动线。
5. 猫砂盆位置优先好清洁和通风，不要只为了隐藏而塞进密闭柜。

你要问的话：

- 猫砂盆附近有没有插座，通风和清洁是否方便？
- 喂食机、饮水机是否会挡路或被门撞？
- 扫地机器人上下水现在做还是后补？
- 洗地机充电、倒污水、晾干在哪里完成？

可复制话术：

```text
家里有两只猫，需要自动猫砂盆、自动喂食机、饮水机的位置和插座。猫设备可以外露，优先好清洁、可通风、不挡通道，不做高价隐藏柜。扫地机器人和洗地机都要保留位置；扫地机器人上下水可以后补，但请先帮我评估靠近水源/排水的可行性，并至少预留停靠位和插座。洗地机要有充电和倒污水方便的位置。
```

报价单必须写清：

- 猫设备插座点位。
- 扫地机器人停靠位插座。
- 扫地机器人上下水如现在做，进水、排水、开孔和安装费单独写。
- 洗地机充电位置。
- 宠物隐藏柜、清洁柜不默认包含。

验收：

- 猫设备插座通电且位置安全。
- 扫地机器人能停靠，不挡门和通道。
- 洗地机有充电和临时放置位置。
- 猫砂盆位置易清洁、可通风。

不要做：

- 不把猫砂盆塞进不通风密闭柜。
- 不为了扫地机器人上下水大改水路。
- 不做高价宠物柜或清洁柜作为默认项。

付款/确认节点：

- 水电验收时确认宠物和清洁设备插座。
- 扫地机器人上下水如后补，等设备确定后单独报价。
