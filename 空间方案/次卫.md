# 次卫

这项是什么：客卫或公卫，也完整保留并带淋浴，方便老人和客人使用。

谁来做：

- 你：确认基础洁具，不降成半卫。
- 工长/防水/瓦工：防水、贴砖、坡度。
- 洁具商家：安装。

预算卡法：

- 次卫也带淋浴，但配置用基础款。
- 和主卫一样重视防水，材料可选便宜基础款。

分区建议：

- 淋浴区墙面：必须贴砖，至少1.8米，建议到吊顶底。
- 台盆区：台面以上至少1.2米防溅处理。
- 马桶区：靠近淋浴则贴砖到1.2米以上或到吊顶底。
- 干区小墙：不直接淋水可刷防潮耐擦洗漆，但卫生间小且潮时建议全砖更稳。

具体步骤：

1. 水电前确认次卫也有花洒、浴霸、地漏。
2. 确认马桶坑距不大改。
3. 防水闭水和主卫同标准。
4. 贴砖后验坡度和排水。
5. 安装洁具后试水。

你要问的话：

- 次卫是否也按完整淋浴防水做？
- 浴霸和排风是否有点位？
- 淋浴区是否需要挡水条？

可复制话术：

```text
次卫也要完整保留并带淋浴，不做半卫。配置可以基础，但防水、闭水、地漏坡度不能省。马桶位尽量不动，淋浴区墙砖和防水高度请按正常淋浴区做。
```

报价单必须写清：

- 次卫防水面积和高度。
- 墙砖地砖面积。
- 花洒、马桶、浴室柜或台盆。
- 地漏、浴霸、排风。
- 挡水条或浴帘杆。

验收：

- 闭水通过。
- 淋浴排水顺。
- 马桶、花洒、台盆无漏水。
- 插座和浴霸安全可用。

不要做：

- 不把次卫简化到没有淋浴。
- 不为了省钱省闭水。
- 不做高端洁具。

付款/确认节点：

- 同主卫，闭水和洁具试水通过后再付款。
