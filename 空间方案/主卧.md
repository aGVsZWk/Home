# 主卧

这项是什么：你自己住的房间，优先保证睡眠、收纳、床头用电。

谁来做：

- 你：确认床、衣柜、灯、插座。
- 工长/电工/油工：水电、墙面、灯。
- 定制商家：主卧衣柜。

预算卡法：

- 主卧优先做衣柜。
- 床、床垫、窗帘可按预算后补。
- 不做背景墙、复杂吊顶。

具体步骤：

1. 开工交底前确定床大概位置。
2. 床头两侧各留插座。
3. 衣柜位置不要挡门和窗。
4. 墙面暖白乳胶漆。
5. 地面浅木色强化复合地板。
6. 灯具用基础吸顶灯。

你要问的话：

- 床头插座够不够？
- 衣柜开门是否影响床？
- 空调插座位置是否合适？

可复制话术：

```text
主卧我自己住，做基础原木风：暖白墙、浅木色地板、普通吸顶灯、主卧衣柜。床头两侧请各留插座，不做床头背景墙、不做吊顶、不做无主灯。
```

报价单必须写清：

- 主卧墙面面积。
- 地板面积。
- 门和踢脚线。
- 衣柜尺寸和价格。
- 插座点位。
- 灯具安装。

验收：

- 床头插座位置合理。
- 衣柜开门顺畅。
- 墙面和地板无明显问题。
- 灯具亮度够用。

不要做：

- 不做床头背景墙。
- 不做复杂吊顶。
- 不做灯带。
- 不做过多定制柜。

付款/确认节点：

- 主卧衣柜、地板、灯具分别按安装验收付款。
