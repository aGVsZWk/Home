# Home Wiki

这个 wiki 用来集中整理装修、施工、采购、风格参考、户型图和 3D 模型资料。

## 快速开始

```bash
npm install
npm run wiki:serve
```

本地预览默认运行在 <http://localhost:4000>。

## 构建静态站点

```bash
npm run wiki:build
```

构建产物会生成到 `_book/`，可以部署到任意静态站点服务。
