# 2.5 地面找平

这项是什么：把地面处理到能铺砖或铺地板的平整状态。

谁来做：

- 你：确认哪些区域找平、铺砖还是铺地板。
- 工长/瓦工：找平施工。
- 地板商家：安装前复测地面平整度。

预算卡法：

- 目标：3000-8000，按实际面积看。
- 卧室铺强化复合地板时，地面不平会影响后期异响。

开工前确认：

- 哪些区域铺砖，哪些区域铺地板。
- 卧室地板商家对平整度的要求。
- 找平厚度是否影响门槛和门洞。

施工中你看什么：

- 找平区域是否和报价一致。
- 表面是否大面积开裂、起砂。
- 是否预留足够养护时间。

拍照留档：

- 找平前地面。
- 找平完成后的整体地面。
- 地板商家复测结果。

返工风险：

- 地面不平会导致地板异响、起翘。
- 找平过厚可能影响门和地面高差。

具体步骤：

1. 开工前定客餐厅铺砖、卧室铺强化复合地板。
2. 瓦工阶段确认卧室地面是否需要找平。
3. 地板安装前让商家复测地面平整。
4. 不平的地方先处理，再装地板。

你要问的话：

- 哪些区域需要找平？
- 找平厚度多少？
- 找平后多久能铺地板？
- 找平费用是否包含在半包？

可复制话术：

```text
卧室我要铺强化复合地板，请先确认地面平整度。需要找平的区域请写清面积、厚度、单价和总价。地板安装前如果地面不平导致异响，请提前处理，不要装完再说。
```

报价单必须写清：

- 找平区域。
- 面积。
- 厚度。
- 单价。
- 材料和人工是否包含。
- 是否含养护。

验收：

- 地面无明显高低差。
- 找平层无大面积开裂、空鼓。
- 地板安装前商家认可可安装。

不要做：

- 不为了省找平导致地板后期大面积异响。
- 不做没必要的全屋厚找平。

付款/确认节点：

- 找平完成并确认可进入下一道工序后付款。
