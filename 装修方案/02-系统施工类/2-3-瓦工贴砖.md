# 2.3 瓦工贴砖

这项是什么：厨房、卫生间、阳台、客餐厅地面贴砖，包含找平、铺贴、坡度、包管、收口等。

谁来做：

- 你：买砖或确认砖、确认铺贴方式、验空鼓和坡度。
- 工长/瓦工：找平、铺贴、包管、收口、地漏坡度。

预算卡法：

- 半包人工辅料目标：12000-20000。
- 瓷砖主材目标：8000-14000。
- 选常规规格，少选小砖、异形砖、斜铺、鱼骨拼。

开工前确认：

- 瓷砖规格、数量、损耗和铺贴方向。
- 厨房、两个卫生间、阳台、客餐厅分别贴什么砖。
- 地漏、门槛石、挡水条是否到场。

施工中你看什么：

- 卫生间地面是否向地漏找坡。
- 砖缝是否明显歪斜。
- 地漏、门槛、阴阳角周边是否收口粗糙。

拍照留档：

- 试铺效果。
- 地漏坡度和地漏位置。
- 包管、门槛石、挡水条。
- 贴砖完成后的整面墙和地面。

返工风险：

- 空鼓过多，后期瓷砖可能脱落或开裂。
- 卫生间坡度不对，洗澡积水。
- 小砖和复杂铺法会拉高人工费。

具体步骤：

1. 贴砖前确定砖的规格、数量、损耗、铺贴方向。
2. 客餐厅用浅色普通砖或浅木纹砖，别追大规格网红砖。
3. 厨房和两个卫生间墙地砖提前送到现场。
4. 让瓦工先试铺一小块，看颜色和方向。
5. 卫生间地面重点看坡度，水要流向地漏。
6. 贴完用空鼓锤或硬物轻敲检查空鼓。
7. 阴阳角、门槛、地漏周边拍照留档。

你要问的话：

- 贴砖人工按平米还是按项目？
- 大砖、小砖、加工砖是否另收费？
- 包管、门槛石、地漏安装、倒角是否包含？
- 空鼓超过多少负责整改？

可复制话术：

```text
瓷砖我会选常规规格，预算紧，不做复杂铺法。请把贴砖面积、人工单价、水泥沙子或瓷砖胶、包管、门槛石安装、地漏安装、倒角、空鼓整改规则写清。卫生间地面坡度要保证排水，贴完我会验空鼓和地漏排水。
```

报价单必须写清：

- 墙砖、地砖铺贴面积。
- 普通砖和大砖人工单价。
- 水泥、沙子、瓷砖胶、背胶是否包含。
- 包立管是否包含。
- 门槛石/挡水条安装是否包含。
- 地漏安装和坡度处理是否包含。
- 空鼓整改标准。

验收：

- 大面积无明显空鼓。
- 砖缝均匀，表面无明显高低差。
- 卫生间和阳台地漏排水顺。
- 墙砖阴阳角顺直。
- 地砖无明显翘角、破损。

不要做：

- 不做小花砖大面积铺贴。
- 不做鱼骨拼、斜铺、复杂拼花。
- 不盲目上大规格岩板砖。
- 不为了好看牺牲卫生间排水坡度。

付款/确认节点：

- 防水闭水通过后贴砖。
- 瓦工验收通过后付瓦工节点款。
