# 2.4 墙面基层与乳胶漆

这项是什么：处理墙面基层，刮腻子、打磨、刷底漆和面漆，让全屋墙面干净平整。低配原木风主要靠暖白墙面打底。

快速清单：

| 你要确认 | 默认做法 |
|---|---|
| 是否铲墙 | 让工长现场说明理由 |
| 墙面颜色 | 暖白或白色乳胶漆 |
| 谁施工 | 油工施工，你不自己刷 |
| 重点验收 | 空鼓、裂缝、平整、透底、流坠 |
| 付款 | 验收通过后付油工节点款 |

谁来做：

- 你：确认颜色和品牌，看基层问题，验收墙面。
- 工长/油工：铲墙、修补、找平、挂网、腻子、打磨、刷漆。

预算卡法：

- 目标：8000-13000。
- 全屋乳胶漆最省钱。
- 不做艺术漆、微水泥、墙布、护墙板。

开工前确认：

- 是否铲墙，以及工长给出的理由。
- 墙面裂缝、空鼓、渗水是否先处理。
- 乳胶漆颜色和品牌。

施工中你看什么：

- 腻子遍数是否和报价一致。
- 阴阳角是否明显歪斜。
- 打磨后墙面是否有明显波浪。

拍照留档：

- 铲墙或基层处理前后。
- 裂缝修补和挂网位置。
- 刷漆前确认色卡。
- 刷完后的白天和夜晚墙面。

返工风险：

- 基层没处理好，后期开裂、起皮。
- 深色漆更容易显瑕疵，也更难补。
- 未确认颜色就刷，返工会很麻烦。

具体步骤：

1. 开工前确认墙面是否需要铲墙，让工长现场报“铲墙/不铲墙”的理由。
2. 让报价单写清楚：铲墙、修补、找平、挂网、腻子几遍、打磨、底漆、面漆分别是否包含。
3. 你自己只买或确认乳胶漆颜色和品牌，不自己刷。
4. 油工进场前，确认墙面空鼓、裂缝、渗水有没有处理。
5. 腻子完成后看墙面平整度和阴阳角。
6. 刷漆前确认颜色，建议全屋暖白。
7. 刷完后白天和晚上各看一次，有透底、流坠、开裂就让整改。
8. 验收通过后再付油工节点款。

你要问的话：

- 是否铲墙？为什么？
- 腻子几遍？
- 是否含底漆和两遍面漆？
- 裂缝和阴阳角怎么处理？
- 乳胶漆品牌、型号、用量写不写？

可复制话术：

```text
墙面我做低配原木风，默认暖白乳胶漆，不做艺术漆和墙布。请帮我写清是否铲墙、裂缝修补、找平、挂网、腻子几遍、打磨、底漆、面漆、乳胶漆品牌型号和面积。刷完我会白天晚上各看一次，有透底、流坠、开裂、阴阳角明显歪斜请整改。
```

报价单必须写清：

- 是否铲墙。
- 是否修补裂缝。
- 是否挂网。
- 石膏找平是否包含。
- 腻子几遍。
- 是否含打磨。
- 是否含底漆。
- 是否含面漆。
- 乳胶漆品牌、型号、用量。
- 单价、面积、总价。

验收：

- 墙面无明显裂缝、起皮、透底。
- 侧光看没有特别明显波浪。
- 阴阳角基本顺直。
- 开关、门套、踢脚线周边收口干净。
- 颜色和确认色一致。

不要做：

- 不做艺术漆。
- 不做微水泥。
- 不做墙布。
- 不做大面积护墙板。
- 不用深色墙面增加修补难度。

付款/确认节点：

- 腻子前确认基层处理范围。
- 刷漆前确认颜色。
- 墙面验收通过后付油工节点款。
