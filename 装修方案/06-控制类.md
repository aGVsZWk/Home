# 控制类

## 6.1 报价沟通

为什么这样做：半包最怕低价进场、后期增项。你要让每家按同一口径报价。

具体怎么执行：

1. 给每家同一段需求。
2. 要明细，不接受一句“半包总价”。
3. 让对方列可能增项。
4. 对比漏项，而不是只比总价。
5. 对不清楚的项目逐项追问。

你要说的话：

```text
请不要只给我总价。我要看每个项目的面积、单价、总价、施工范围、辅材品牌和可能增项。报价里不含的项目也请明确写出来，避免后面扯皮。
```

对方常见套路：

- 把水电报很低，后期按实际猛加。
- 漏掉垃圾清运、材料上楼、包管、找平。
- 主材套餐写得模糊。
- 口头说包含，合同不写。

你怎么挡：

- 所有口头承诺写进报价或合同。
- 增项必须书面确认。
- 每个项目问“这个不含什么”。

什么时候算通过：

- 报价能横向对比。
- 你知道哪些项目含，哪些不含。
- 你知道哪些可能加钱。

## 6.2 阶段验收

为什么这样做：验收是你的刹车，不验收就付款，后面很难让人返工。

具体怎么执行：

1. 水电验收：看点位、打压、通电、拍照。
2. 防水验收：闭水24-48小时，楼下确认。
3. 瓦工验收：看空鼓、坡度、地漏排水、阴阳角。
4. 油工验收：看墙面裂缝、透底、流坠、阴阳角。
5. 安装验收：看门、柜、洁具、灯、开关插座。
6. 竣工验收：列整改清单，整改完付尾款。

你要说的话：

```text
每个节点我都会先验收再付款。验收发现的问题我会拍照列清单，请整改完成后再进入下一笔付款。
```

对方常见套路：

- 说“小问题后面一起修”。
- 催下一笔款。
- 说“行业都这样”。

你怎么挡：

- 小问题也写清单。
- 没整改就不付对应尾款。
- 只按合同节点付款。

什么时候算通过：

- 问题清单清零。
- 隐蔽工程有照片。
- 水电、防水、瓦工、油工、安装都有验收记录。

## 6.3 付款确认

为什么这样做：钱是你最重要的控制工具。付太快，整改动力会变弱。

具体怎么执行：

推荐付款节奏：

| 节点 | 比例 |
|---|---:|
| 开工 | 20%-30% |
| 水电验收后 | 25%-30% |
| 瓦工验收后 | 25%-30% |
| 油工结束后 | 10%-15% |
| 竣工整改后 | 5%-10%尾款 |

你要说的话：

```text
我按节点付款。每个节点验收通过再付下一笔，竣工尾款保留5%-10%，整改完成后结清。未经我书面确认的增项不付款。
```

对方常见套路：

- 开工前要大额款。
- 增项先干后报。
- 尾款前说问题以后再修。

你怎么挡：

- 开工款不超过30%。
- 增项先确认再施工。
- 尾款和整改绑定。

什么时候算通过：

- 付款比例写进合同。
- 每次付款都有对应验收。
- 尾款没提前付完。

## 6.4 背景墙不做

为什么这样做：背景墙花钱快，但对入住功能帮助小。预算紧时它是第一批砍掉的项目。

具体怎么执行：

1. 客厅电视墙只刷乳胶漆。
2. 床头墙只刷乳胶漆。
3. 不做岩板、木饰面、格栅、硬包、灯带。
4. 后期用成品电视柜、挂画、窗帘和家具补氛围。

你要说的话：

```text
我家预算紧，背景墙全部不做。客厅和卧室墙面只刷暖白乳胶漆，不做岩板、木饰面、格栅、灯带、硬包。报价里不要加背景墙项目。
```

对方常见套路：

- 说“不做背景墙不像装修”。
- 推荐套餐升级。
- 说原木风必须木饰面。

你怎么挡：

- 原木风靠浅木色地板、柜门、家具做。
- 背景墙以后有钱再说。

什么时候算通过：

- 报价里没有背景墙。
- 水电没有为背景墙增加灯带和插座。

## 6.5 软装后补

为什么这样做：软装可以入住后慢慢买，不该挤占水电、防水、瓦工的钱。

具体怎么执行：

1. 硬装阶段只确定窗帘盒是否需要，预算紧可不做。
2. 入住前买基础窗帘、床、床垫。
3. 餐桌、沙发、电视柜、书桌按刚需慢慢补。
4. 装饰画、地毯、摆件最后再买。

你要说的话：

```text
软装我后期慢慢补。现在硬装预算优先水电、防水、瓦工、墙面、基础主材和刚需柜。窗帘、装饰画、地毯、餐边柜、电视柜都不要提前塞进硬装报价。
```

对方常见套路：

- 软装套餐打包。
- 推荐全屋一站式。
- 让你提前买一堆装饰。

你怎么挡：

- 能后补的一律后补。
- 先能住，再变漂亮。

什么时候算通过：

- 硬装报价不混入软装。
- 家具家电单独做预算。
