# 主材与安装类

## 3.1 客餐厅浅色砖或木纹砖

这项是什么：客餐厅地面主材，是低配原木风的视觉底色之一。

谁来做：

- 你：选砖、比价、确认数量和损耗。
- 商家：送货、补货、退货规则。
- 瓦工：铺贴。

预算卡法：

- 目标：6000-12000，取决于面积和砖价。
- 选常规浅色砖或浅木纹砖。
- 不追进口、大牌旗舰、超大规格。

具体步骤：

1. 先确定客餐厅铺砖，不做木地板通铺。
2. 去本地市场或线上看浅米、浅灰、浅木纹。
3. 问清每平价格、损耗、送货、上楼、退补货。
4. 拿小样放到自然光下看颜色。
5. 下单前让瓦工确认规格是否会增加人工费。

你要问的话：

- 这款砖每平多少钱？
- 是否同批次？
- 送货和上楼多少钱？
- 补货是否有色差？
- 退货规则是什么？

可复制话术：

```text
我做低配原木风，客餐厅想选浅色普通砖或浅木纹砖，预算紧，不要高端款。请给我每平价格、损耗建议、送货上楼费、补货规则、退货规则，并确认这个规格不会让瓦工额外加很多人工费。
```

报价单必须写清：

- 瓷砖品牌/产地。
- 规格。
- 单价。
- 数量。
- 损耗。
- 送货、上楼费用。
- 补货和退货规则。

验收：

- 到货数量和型号一致。
- 砖面无大面积破损。
- 铺完色差不明显。
- 地面无明显空鼓和翘角。

不要做：

- 不做岩板。
- 不做超大规格砖。
- 不做复杂拼花。
- 不为“更像木头”买很贵木纹砖。

付款/确认节点：

- 下单前确认退补货。
- 到货验收后确认收货。
- 铺贴验收走瓦工节点。

## 3.2 卧室强化复合地板

这项是什么：卧室地面材料。强化复合地板便宜、脚感比砖温和，适合预算紧的低配原木风。

谁来做：

- 你：选颜色、厚度、环保等级、价格。
- 地板商家：测量、送货、安装、售后。
- 工长：配合地面找平和门槛收口。

预算卡法：

- 目标：5000-9000。
- 选浅木色强化复合地板。
- 不做实木地板，不做三层实木。

具体步骤：

1. 瓦工阶段确认卧室地面找平。
2. 油工后期让地板商家复尺。
3. 选择浅木色、耐看、基础款。
4. 问清地板、踢脚线、扣条、防潮膜、安装是否包含。
5. 安装后检查异响、起翘、缝隙。

你要问的话：

- 每平价格含不含安装？
- 踢脚线多少钱？
- 扣条多少钱？
- 防潮膜是否包含？
- 地面不平能不能安装？

可复制话术：

```text
卧室我选浅木色强化复合地板，预算紧，不要实木和高端款。请写清每平价格、环保等级、厚度、安装费、踢脚线、扣条、防潮膜、送货上楼、售后。安装前请先确认地面平整度。
```

报价单必须写清：

- 地板品牌、型号、厚度。
- 环保等级。
- 单价和面积。
- 安装费。
- 踢脚线价格。
- 扣条价格。
- 防潮膜是否包含。
- 送货上楼费。

验收：

- 地板无明显破损。
- 走动无大面积异响。
- 边角收口整齐。
- 门口扣条稳固。

不要做：

- 不做实木地板。
- 不做很深色地板。
- 不买高价进口地板。

付款/确认节点：

- 安装完成、无明显问题后付尾款。

## 3.3 室内门

这项是什么：卧室门、卫生间门、厨房门或门套，是基础主材。

谁来做：

- 你：选基础门款和颜色。
- 门商家：测量、生产、安装。
- 工长：配合门洞修补。

预算卡法：

- 目标：4500-8000。
- 卧室普通复合门，卫生间铝镁合金门。
- 不做隐形门、高门、复杂造型门。

具体步骤：

1. 瓦工阶段后让门商家第一次测量。
2. 地面完成高度确定后复尺。
3. 选普通木色或白色。
4. 问清门、门套、锁、合页、门吸、安装是否包含。
5. 安装后试开关、看门缝、看门锁。

你要问的话：

- 一樘门包含哪些东西？
- 门套、锁具、合页、门吸是否另算？
- 卫生间门防潮怎么样？
- 安装和上楼是否收费？

可复制话术：

```text
室内门我只要基础款，卧室普通复合门，卫生间铝镁合金门，颜色选木色或白色，不做隐形门和复杂造型。请写清每樘门包含门套、锁、合页、门吸、安装、上楼没有，超高或非标怎么算。
```

报价单必须写清：

- 门类型。
- 单价和数量。
- 门套是否包含。
- 锁具、合页、门吸是否包含。
- 安装费。
- 上楼费。
- 非标加价规则。

验收：

- 门开关顺畅。
- 门缝均匀。
- 门锁正常。
- 门套收口平整。
- 卫生间门不怕水汽。

不要做：

- 不做隐形门。
- 不做一门到顶。
- 不做高价烤漆复杂造型。

付款/确认节点：

- 复尺确认后付生产款。
- 安装验收后付尾款。

## 3.4 开关插座

这项是什么：插座面板、开关面板和弱电面板，影响日常使用便利。

谁来做：

- 你：确认品牌、颜色、数量。
- 电工：安装、测试。

预算卡法：

- 目标：1500-3500。
- 选国产基础品牌，不买智能全屋。
- 重点位置留够，不盲目堆数量。

具体步骤：

1. 水电定位时确认点位。
2. 油工后期购买面板。
3. 颜色选白色，最便宜也最百搭。
4. 安装后逐个测试通电和开关控制。

重点点位清单：

- 厨房：烟机、灶具、冰箱、洗碗机、净水器、导台/吧台、餐桌旁、高频小电器台面插座。
- 书房：电脑主机/显示器、路由或网口、相机电池/无人机电池/3D打印机预留插座。
- 客厅影音：电视墙电源、网口、HDMI/eARC线管、回音壁、低音炮、后环绕电源。
- 阳台：洗衣机、烘干机、分桶洗衣机预留插座，位置要避开明水并方便检修。
- 宠物和清洁：自动猫砂盆、自动喂食机、饮水机、扫地机器人、洗地机充电位。
- 现有大件：公路车和椭圆机附近如需充电、维护灯或设备电源，开工交底时一次标清。

你要问的话：

- 面板数量多少？
- 五孔、带开关、网口、电视口分别多少？
- 安装是否包含在半包？
- 厨卫插座是否需要防溅盒？

可复制话术：

```text
开关插座我选白色基础款，不做全屋智能。请帮我按房间列清数量：五孔、带开关、空调插座、厨房插座、卫生间防溅插座、网口。厨房要考虑导台/吧台和高频小电器，书房要考虑电脑、网口、摄影/无人机/3D打印设备充电，客厅要考虑85寸电视和回音壁/低音炮/后环绕，阳台要考虑洗衣机、烘干机、分桶洗衣机，猫设备和清洁设备也要有插座。安装后请逐个通电测试。
```

报价单必须写清：

- 品牌和系列。
- 各类型数量。
- 单价。
- 安装费是否包含。
- 防溅盒是否包含。

验收：

- 每个插座通电。
- 开关控制正确。
- 面板安装平整。
- 厨卫必要位置有防溅。

不要做：

- 不做全屋智能开关。
- 不买高价金属面板。
- 不在水源太近位置乱装普通插座。

付款/确认节点：

- 安装测试通过后付款。

## 3.5 灯具

这项是什么：客餐厅、卧室、厨房、卫生间、阳台的基础照明。

谁来做：

- 你：购买基础灯具。
- 电工/安装师傅：安装、测试。

预算卡法：

- 目标：1500-3500。
- 吸顶灯为主。
- 不做无主灯，不做大量射灯灯带。

具体步骤：

1. 水电定位时只留基础灯位。
2. 客餐厅选简单吸顶灯。
3. 卧室选简单吸顶灯。
4. 厨卫灯和浴霸配合吊顶安装。
5. 阳台选基础灯。
6. 安装后晚上测试亮度。

你要问的话：

- 灯具安装费怎么算？
- 浴霸和吊顶谁负责开孔安装？
- 客厅一个主灯够不够？
- 色温选多少？

可复制话术：

```text
灯光我做基础吸顶灯，不做无主灯、灯带和复杂吊顶。客餐厅、卧室、阳台只留基础灯位。厨卫灯和浴霸请配合铝扣板吊顶安装，安装后帮我逐个测试。
```

报价单必须写清：

- 灯具数量。
- 单价。
- 安装费。
- 浴霸或厨卫灯是否包含。
- 开孔费是否包含。

验收：

- 灯能正常开关。
- 亮度够用。
- 灯具固定牢。
- 浴霸、排风正常。

不要做：

- 不做无主灯。
- 不做磁吸轨道灯。
- 不做复杂灯带。
- 不买过大水晶灯。

付款/确认节点：

- 安装测试正常后付款。

## 3.6 洁具卫浴

这项是什么：两个卫生间的马桶、花洒、浴室柜、地漏、角阀、软管、五金等。

谁来做：

- 你：买基础洁具，确认尺寸。
- 商家/安装师傅：配送、安装、调试。
- 工长：协调水电和收口。

预算卡法：

- 目标：7000-12000，两个卫生间都能用。
- 国产基础款即可。
- 智能马桶、玻璃淋浴房后补。

具体步骤：

1. 水电前确认马桶坑距、浴室柜宽度、花洒位置。
2. 瓦工前买好地漏。
3. 安装前确认马桶、浴室柜、花洒尺寸。
4. 两个卫生间都配马桶、花洒、浴室柜或基础台盆。
5. 安装后逐个试水、试排水、看漏水。

你要问的话：

- 马桶坑距多少？
- 浴室柜宽度适不适合？
- 花洒冷热水间距是否标准？
- 安装费是否包含？
- 角阀、软管、玻璃胶是否另算？

可复制话术：

```text
两个卫生间都要完整保留并带淋浴，但预算紧。我买国产基础款：马桶、花洒、浴室柜、地漏、角阀软管。请写清安装费、辅材费、坑距要求、尺寸要求。淋浴房先不默认做，可以先用浴帘或简单挡水。
```

报价单必须写清：

- 马桶品牌、型号、坑距、数量。
- 花洒品牌、型号、数量。
- 浴室柜尺寸、材质、数量。
- 地漏数量和类型。
- 角阀、软管、下水是否包含。
- 安装费。
- 送货上楼费。

验收：

- 马桶冲水正常，不漏水。
- 花洒冷热水正常。
- 浴室柜排水正常，不漏水。
- 地漏排水顺。
- 玻璃胶收口整齐。

不要做：

- 不默认智能马桶。
- 不默认玻璃淋浴房。
- 不买高端花洒。
- 不做壁龛。

付款/确认节点：

- 安装并试水无漏后付安装尾款。

## 3.7 中央空调

这项是什么：全屋一拖多中央空调系统，包含外机、内机、铜管、冷凝水管、电源、风口、回风口、检修口和安装调试。你现在的意向是小米双风轮6匹1拖5。

谁来做：

- 你：决定是否真的保留中央空调，拿完整报价，确认预算是否扛得住。
- 空调商家/安装方：上门勘测、出布置图、安装内外机和管线、调试。
- 工长/水电师傅：按空调方案预留电源、开槽、冷凝水、吊顶配合。
- 木工/吊顶方：按空调图做必要局部吊顶、风口、回风口、检修口。

预算卡法：

- 这是重大升级项，不计入原来的极限硬装基础预算。
- 报价必须拆开：设备、安装、铜管、冷凝水管、风口、打孔、高空费、加长管、吊顶配合。
- 如果总预算压不住，第一替代方案是普通分体空调：客厅柜机或风管机 + 卧室挂机。

开工前确认：

- 外机位能不能放6匹外机，物业是否允许。
- 5个内机分别放在哪：客厅、主卧、老人房、书房，以及是否还包含餐厅/过道。
- 每个内机是否需要吊顶，吊顶会压低多少层高。
- 冷凝水怎么排，坡度够不够，是否会倒灌或滴水。
- 回风口、出风口、检修口是否好看且能维修。
- 电源是否需要独立回路，线径和空开由专业方确认。
- 铜管超长、打孔、高空作业、外机支架是否另收费。

具体步骤：

1. 在水电开工前约小米或授权安装方上门勘测。
2. 要一张空调布置图：外机位置、5个内机位置、铜管走向、冷凝水走向、风口和检修口。
3. 把布置图发给工长、水电师傅、吊顶方一起确认。
4. 让空调商家给完整报价，不能只报设备价。
5. 如果报价导致总预算明显爆掉，马上改普通分体空调，不要拖到水电后再反悔。
6. 如果确认保留，水电阶段先做电源和冷凝水配合，吊顶阶段按图留风口和检修口。
7. 安装调试后逐个房间试制冷、试排水、听噪音、看风口是否漏风。

你要问的话：

- 6匹1拖5适不适合我这个户型和外机位？
- 5个内机分别放哪里？
- 每个房间吊顶要吊多宽、多高？
- 冷凝水排到哪里，坡度够不够？
- 报价是否包含铜管、风口、打孔、支架、高空费、加长管？
- 后期检修口在哪里，会不会很丑？
- 如果某个房间不做内机，能不能改成普通挂机更省钱？

可复制话术：

```text
我家预算紧，但现在倾向小米双风轮6匹1拖5中央空调。请先上门勘测，不要只报设备价。我要完整方案：外机位、5个内机位置、铜管走向、冷凝水走向、每个房间吊顶范围、出风口回风口检修口、电源要求，以及设备、安装、铜管、打孔、支架、高空费、加长管、风口全部明细报价。如果预算或层高不合适，请直接告诉我，我会考虑改普通分体空调。
```

报价单必须写清：

- 设备型号和数量。
- 外机、内机数量和对应房间。
- 标配铜管长度，超长每米多少钱。
- 冷凝水管是否包含。
- 风口、回风口、检修口是否包含。
- 打孔、支架、高空作业是否包含。
- 电源和空开要求。
- 安装、调试、质保。
- 吊顶配合是否另算。

验收：

- 每个房间出风正常。
- 冷凝水排水顺，不滴水、不倒灌。
- 风口、回风口、检修口位置合理。
- 吊顶无明显压抑和粗糙收口。
- 外机固定牢，运行无异常噪音。

不要做：

- 不先下单再让施工队“想办法塞进去”。
- 不接受只有设备价、没有安装辅材明细的报价。
- 不为了中央空调做全屋满吊。
- 不把检修口藏死。
- 不在预算爆掉时硬撑中央空调。

付款/确认节点：

- 出方案和完整报价后再付定金。
- 内外机和管线安装完成、打压/排水检查后付阶段款。
- 调试通过后付尾款。
