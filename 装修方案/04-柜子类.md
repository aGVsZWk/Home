# 柜子类

## 4.1 厨房橱柜

这项是什么：厨房地柜、吊柜、台面、柜门、基础五金，是厨房刚需。

谁来做：

- 你：确认预算、颜色、布局、要不要预留升级位。
- 橱柜商家：测量、设计、水电建议、生产、安装。
- 工长：按橱柜水电建议施工。

预算卡法：

- 目标：8000-15000。
- 普通地柜 + 少量吊柜 + 石英石台面 + 双饰面门板。
- 不做高柜、灯带、玻璃门、大量拉篮。

具体步骤：

1. 开工前让橱柜商家第一次上门看厨房。
2. 让商家给水电建议图。
3. 水电阶段按水槽、烟机、灶具、冰箱、预留洗碗机/净水器位置留点。
4. 瓦工结束后复尺。
5. 签单前确认地柜米数、吊柜米数、台面、抽屉数量、五金。
6. 安装后检查柜门、台面、水槽、烟机灶具开孔。

你要问的话：

- 地柜多少钱一米？吊柜多少钱一米？
- 台面是否单算？
- 几个抽屉包含？
- 水槽、龙头、拉篮是否包含？
- 见光板、封板、踢脚线、开孔是否加钱？

可复制话术：

```text
厨房我做常规厨房加预留升级位，现在只做基础橱柜、烟机灶具、水槽龙头。请给我地柜、吊柜、台面分别报价，柜体板材、柜门材质、五金、抽屉数量、封板、见光板、踢脚线、开孔、安装都写清。洗碗机、净水器、蒸烤箱现在不买，但请预留位置和插座建议。
```

报价单必须写清：

- 地柜米数、单价、总价。
- 吊柜米数、单价、总价。
- 台面材质、单价、总价。
- 柜体板材。
- 柜门材质。
- 铰链、轨道品牌。
- 抽屉数量。
- 拉篮是否包含。
- 见光板、封板、踢脚线是否包含。
- 水槽开孔、灶具开孔是否包含。
- 设计、测量、安装、运输是否包含。

验收：

- 柜体稳固。
- 柜门缝隙基本一致。
- 台面无明显破损。
- 水槽不漏水。
- 烟机、灶具开孔尺寸正确。
- 预留插座没有被柜体挡死。

不要做：

- 不做高柜。
- 不做玻璃门。
- 不做灯带。
- 不做大量拉篮。
- 不做高价肤感/PET门板。

付款/确认节点：

- 初尺不付大额款。
- 复尺方案确认后付生产款。
- 安装验收后付尾款。

## 4.2 主卧衣柜

这项是什么：主卧刚需收纳，预算紧时只做主卧衣柜，不默认全屋铺满。

谁来做：

- 你：确认尺寸、板材、柜门、内部格局。
- 定制商家：测量、设计、生产、安装。

预算卡法：

- 目标：6000-10000。
- 双饰面门板，基础五金。
- 少抽屉，少开放格，不做灯带。

具体步骤：

1. 确认床位置和衣柜位置。
2. 让商家测量墙宽、高度、梁柱。
3. 只做够用衣柜，不做整面复杂收纳墙。
4. 签单前确认投影面积、展开面积算法。
5. 确认抽屉数量、挂衣区、层板、封板是否包含。
6. 安装后检查柜门、五金、封边、气味。

你要问的话：

- 按投影面积还是展开面积？
- 每平包含什么？
- 抽屉几个？
- 顶封板、侧封板、拉手、挂衣杆是否包含？
- 超高是否加钱？

可复制话术：

```text
主卧衣柜我只做基础够用款，浅木色或白色双饰面，不做玻璃门、灯带、开放格和复杂造型。请按投影面积给我写清单价、尺寸、板材、柜门、五金、抽屉数量、层板、挂衣杆、封板、拉手、安装和运输。
```

报价单必须写清：

- 计价方式。
- 投影面积或展开面积。
- 板材品牌和厚度。
- 柜门材质。
- 五金品牌。
- 抽屉数量。
- 层板数量。
- 挂衣杆数量。
- 封板、收口、拉手是否包含。
- 安装运输是否包含。

验收：

- 尺寸贴合。
- 柜门开关顺畅。
- 封边无明显开胶。
- 柜体无明显破损。
- 五金牢固。

不要做：

- 不做全墙复杂造型。
- 不做玻璃门。
- 不做灯带。
- 不做反弹器。
- 不做大量抽屉。

付款/确认节点：

- 复尺确认后付生产款。
- 安装整改完成后付尾款。

## 4.3 玄关鞋柜

这项是什么：入户收纳，解决鞋子和杂物，建议做但要基础化。

谁来做：

- 你：确认鞋柜长度、深度、是否留换鞋区。
- 定制商家：测量、设计、安装。

预算卡法：

- 目标：3000-6000。
- 平开门、基础层板、少开放格。

具体步骤：

1. 量入户玄关宽度和深度。
2. 确认鞋柜不影响入户门打开。
3. 预算紧时只做下柜或简单到顶柜。
4. 问清层板、封板、拉手、安装。
5. 安装后检查门板和层板。

你要问的话：

- 鞋柜深度多少？
- 能放常用鞋吗？
- 层板几个？
- 是否做到顶？
- 换鞋凳和开放格是否加钱？

可复制话术：

```text
玄关鞋柜我做基础收纳，预算紧，不做灯带和复杂换鞋凳。请写清尺寸、板材、柜门、层板数量、封板、拉手、安装和运输。开放格能少就少，避免加钱和积灰。
```

报价单必须写清：

- 尺寸。
- 计价面积。
- 板材。
- 柜门。
- 层板数量。
- 封板和收口。
- 拉手。
- 安装运输。

验收：

- 不挡入户门。
- 柜门开关顺畅。
- 层板稳。
- 收口整齐。

不要做：

- 不做灯带。
- 不做复杂换鞋凳一体。
- 不做大量开放格。
- 不做玻璃门。

付款/确认节点：

- 安装验收后付尾款。

## 4.4 后补柜子策略

这项是什么：把非刚需柜子从硬装预算里拿出来，等入住后再慢慢补。

谁来做：

- 你：决定哪些先不做。
- 商家：后期按需补充。

预算卡法：

- 现在只保橱柜、主卧衣柜、玄关鞋柜。
- 餐边柜、电视柜、阳台柜、书柜、次卧柜先不默认做。
- 公路车、椭圆机、猫设备可以外露，先不为了隐藏它们做高价定制柜。

具体步骤：

1. 先列刚需柜：橱柜、主卧衣柜、玄关鞋柜。
2. 老人房如果预算够可做基础衣柜；预算紧先买成品柜。
3. 独立书房先买成品书桌、书架或金属架，不做榻榻米。
4. 摄影/无人机/3D打印耗材先用成品架、收纳箱、洞洞板解决，独立设备柜后补。
5. 入住后看真实收纳需求再补。

你要问的话：

- 这个柜子是不是入住第一天就必须？
- 能不能用成品家具替代？
- 做了会不会压缩预算和空间？
- 是不是只是为了把公路车、椭圆机、猫设备藏起来？如果是，先不做。

可复制话术：

```text
我现在只做刚需柜，橱柜、主卧衣柜、玄关鞋柜优先。餐边柜、电视柜、阳台柜、书柜、次卧柜、设备隐藏柜先不默认做，后面入住后看预算再补。两辆公路车、椭圆机、猫设备可以外露靠墙靠边，不为了隐藏它们增加高价定制。报价请不要把这些自动加进去。
```

报价单必须写清：

- 哪些柜子包含。
- 哪些柜子不包含。
- 每个柜子单独报价。
- 不要把“全屋定制套餐”混成一个总价。

验收：

- 报价里没有把后补柜子偷偷算进去。
- 刚需柜单独可核对。

不要做：

- 不做全屋定制铺满。
- 不做榻榻米。
- 不做电视背景柜。
- 不做餐边柜优先级高于水电防水。
- 不做为了“看不见设备”而牺牲预算和通道的隐藏柜。

付款/确认节点：

- 只对已确认的刚需柜付款。
