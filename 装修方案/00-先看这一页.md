# 先看这一页

## 0.1 极限预算总控

先按这个预算卡，不主动加项。

| 类别 | 极限预算 | 怎么卡 |
|---|---:|---|
| 半包施工 | 5万-6万 | 不改格局，水电局部改；默认客餐厅不吊顶，若保留中央空调则局部吊顶另算 |
| 基础主材 | 2.8万-3.5万 | 白墙、浅木色地板/木纹砖、普通木色门，洁具灯具买基础款 |
| 必要柜子 | 1.8万-2.5万 | 只做橱柜、主卧衣柜、玄关鞋柜，柜门选浅木色或白色双饰面 |
| 备用金 | 5000-8000 | 专门防增项、补货、搬运、安装小项 |
| 先入住合计 | 9.8万-12.8万 | 不含大件家具家电，不含全屋定制铺满 |

现金非常紧时按这个最低目标压：

| 项目 | 最低卡法 |
|---|---:|
| 半包施工 | 尽量卡在5.5万以内 |
| 主材 | 尽量卡在3万以内 |
| 柜子 | 尽量卡在2万以内 |
| 备用金 | 至少留5000 |
| 总目标 | 10万-11万先入住 |

三条红线：

- 不乱改格局：厨房、卫生间、马桶位、上下水尽量不动。
- 不碰隐蔽工程质量：水电、防水、瓦工、墙面基层不能为了省钱乱砍。
- 不提前付尾款：每个节点验收通过再付款，竣工尾款等整改完再付。

## 0.3 原木风怎么低价做出来

低配原木风不是买真木头，而是用低成本视觉信号：

- 墙面：全屋暖白或白色乳胶漆。
- 地面：客餐厅浅色砖或浅木纹砖，卧室浅木色强化复合地板。
- 柜门：浅木色或白色双饰面。
- 室内门：普通木色或白色复合门。
- 灯具：简单吸顶灯。
- 软装：入住后慢慢补米白窗帘、木色成品家具。

预算红线：

- 不做无主灯。
- 不做复杂吊顶。
- 不做电视背景墙。
- 不做实木地板。
- 不做大面积木饰面。
- 不做格栅墙。
- 不做隐形门。
- 不做高价肤感/PET柜门。
- 不做全屋定制铺满。
- 不默认立即购买洗碗机、净水器、蒸烤箱。

中央空调提醒：

- 如果确认做小米双风轮6匹1拖5，原来的“客餐厅和卧室不吊顶”要改成“只做必要局部吊顶/边吊/走廊吊顶”。
- 中央空调不是入住前再买的普通家电，它必须在水电前定方案、定内机位置、定外机位、定冷凝水和检修口。
- 如果预算爆了，中央空调仍属于第一批需要重新评估的升级项之一，可以退回普通分体空调方案；但先别砍掉开放式厨房核验、独立书房基础点位和现有大件落位。

## 0.4 你第一周只做这五件事

1. 把“套内约100平、半包、预算紧、低配原木风、不大改厨卫”发给3-5个工长或装修公司约量房。
2. 量房时让对方按同一套需求报价，不接受只报总价。
3. 同时找1-2家橱柜/定制商家上门看厨房，先要厨房水电建议。
4. 建一个报价对比表，只看项目、单价、面积、辅材品牌、增项条件。
5. 不交大定，不签套餐，不接受“今天定最便宜”的催促。

可复制话术：

```text
我家石家庄毛坯房，三室两厅两卫，建筑面积约129平，按套内约100平做。我要半包，预算很紧，目标是先能住，低配原木风。两个卫生间都保留淋浴，卫生间上下水和马桶位尽量不动。厨房我优先要开放式大厨房，想做导台/吧台加餐桌，请先帮我核验物业、燃气、承重墙、烟道和拆改预算，不要直接按普通封闭厨房报价。默认不做背景墙、不做无主灯、不做复杂吊顶；但我正在评估小米双风轮6匹1拖5中央空调，如果保留中央空调，请把必要局部吊顶、风口、检修口和冷凝水单独报价。家里还要安排两位老人1.8米床、带门安静电脑书房、两辆公路车、椭圆机、两只猫的自动设备、摄影/无人机/3D打印设备、85寸电视影音、阳台洗烘和分桶洗衣预留、扫地机器人和洗地机位置。请按人工、辅材、面积、单价、品牌、可能增项给我详细报价。
```

现在最该补齐的第一优先级：

1. 开放式厨房可行性：物业、燃气、承重墙、烟道、门洞、油烟和拆改报价。
2. 中央空调是否最终保留，以及完整上门勘测报价。
3. 橱柜商家和厨房水电建议图，包含导台/吧台、餐桌和高频小电器插座。
4. 水槽、厨房龙头、第二个马桶、两套花洒。
5. 独立书房电脑位、公路车、椭圆机、猫设备、清洁设备、阳台洗烘和分桶洗衣点位。
6. 浴室柜、地漏、室内门、地板、乳胶漆。
7. 开关插座、厨卫吊顶、浴霸、基础灯具。

最省钱的判断规则：

- 影响水电、瓦工、橱柜、吊顶的，先定。
- 已有实物要先找位置：公路车、椭圆机、猫设备不能等入住后再想。
- 影响入住基本功能的，按节点买。
- 只是好看、享受、升级的，后买。
- 电视、影音、洗碗机本体、洗烘套本体、分桶洗衣机本体、扫地机器人上下水、3D打印机独立空间、餐边柜、书柜、电视柜都可以往后压。
