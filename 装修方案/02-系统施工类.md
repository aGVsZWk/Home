# 系统施工类

## 2.1 水电改造

这项是什么：把开关、插座、灯位、水管、下水位置调整到你未来能用的位置。它是隐蔽工程，后期返工最麻烦。

谁来做：

- 你：确认点位、数量、位置、拍照留档、验收后付款。
- 工长/水电师傅：开槽、布管、穿线、改水、测试、封槽。
- 橱柜商家：提供厨房水电建议。

预算卡法：

- 极限目标：7000-10000。
- 超过12000必须拆明细。
- 默认局部改造，不做全屋重排。

开工前确认：

- 家具、电器、床、书桌、橱柜、洗衣机的大概位置。
- 厨房水电建议图。
- 两个卫生间花洒、马桶、浴室柜、浴霸位置。
- 开放式厨房、导台/吧台、餐桌、冰箱和高频小电器位置。
- 独立书房电脑桌、网口、摄影/无人机/3D打印设备充电和收纳位置。
- 85寸电视、回音壁、低音炮、后环绕电源和HDMI/eARC线管。
- 两辆公路车、椭圆机、猫设备、扫地机器人、洗地机的默认外露位置。
- 阳台洗衣机、烘干机、分桶洗衣机预留位置；确认不做阳台洗手台。

施工中你看什么：

- 线管、水管是否按确认点位走。
- 强弱电有没有混在一起。
- 是否出现未经确认的绕线、绕管和新增点位。

拍照留档：

- 厨房水电。
- 两个卫生间水电。
- 阳台洗衣机位。
- 独立书房电脑位、网口、设备充电位。
- 电视墙和后环绕电源位。
- 猫设备、清洁设备、公路车和椭圆机附近插座位。
- 强弱电箱和主要管线走向。

返工风险：

- 点位错了，后期柜子和家具可能挡插座。
- 没拍照，后期打孔容易打到管线。
- 水管没打压，漏水责任难说清。

具体步骤：

1. 开工交底前，先在每个房间想清楚床、桌子、柜子、电器的位置。
2. 让橱柜商家先出开放式厨房水电建议，至少说明水槽、烟机、灶具、冰箱、净水器、洗碗机、导台/吧台和高频小电器预留位。
3. 现场用胶带标出插座、开关、灯位、水位。
4. 让工长现场数点位，并说清楚哪些按点位算、哪些按米数算。
5. 单独核对独立书房、电视影音、猫设备、清洁设备、阳台洗烘和分桶洗衣点位。
6. 水电施工中拍照，尤其是厨房、两个卫生间、阳台洗衣机位置。
7. 水电完工后做水管打压、电路通断、开关控制检查。
8. 你保存照片和视频，再同意封槽。
9. 水电验收通过后，再付水电节点款。

你要问的话：

- 水电是按点位、按米数，还是一口价？
- 强电、弱电、水管分别用什么品牌和规格？
- 厨房和两个卫生间有没有绕线、绕管导致增项？
- 洗碗机、净水器、小厨电只是预留，报价里有没有当成现在购买？
- 书房网口、电视影音、后环绕、猫设备、扫地/洗地、分桶洗衣这些点位有没有逐项列出来？

可复制话术：

```text
水电请按局部改造报价，不做全屋重排。请把强电、弱电、水管、线管品牌规格写清楚，点位数量和单价写清楚。厨房按开放式大厨房预留洗碗机、净水器、小厨电、导台/吧台和餐桌附近插座，但这些电器我现在不全部购买。两个卫生间保留原马桶位，都要花洒和浴霸点位。独立书房要留电脑插座、网口、摄影/无人机/3D打印设备充电位；客厅按85寸电视、回音壁、低音炮和后环绕预留；阳台按洗衣机、烘干机、分桶洗衣机预留，不做洗手台；猫设备、扫地机器人和洗地机要留位置和插座。水电完工后请先拍照验收、水管打压，再封槽。
```

报价单必须写清：

- 强电点位数量、单价、总价。
- 弱电点位数量、单价、总价。
- 水管品牌、规格、米数或计价方式。
- 电线品牌、规格。
- 线管品牌、规格。
- 开槽、封槽是否包含。
- 水管打压是否包含。
- 厨房、卫生间、阳台水位改造是否包含。
- 书房网口、电视影音、猫设备、清洁设备、阳台分桶洗衣等新增点位是否单独列项。
- 超出点位或米数怎么算。

验收：

- 水管打压不掉压。
- 插座通电。
- 开关对应灯位正确。
- 强弱电间距合理，弱电不要和强电混穿。
- 厨房、卫生间、阳台点位和你确认的一致。
- 书房、电视影音、猫设备、清洁设备点位和现场标记一致。
- 拍照能看清管线走向。

不要做：

- 不做全屋重排水电。
- 不为了无主灯增加大量灯位。
- 不把马桶位大幅移位。
- 不把洗碗机、净水器、蒸烤箱当成立即购买项目。

付款/确认节点：

- 水电定位确认后才开工。
- 水电验收、打压、拍照后付节点款。
- 未确认的水电增项不付款。

## 2.2 防水

这项是什么：卫生间、厨房、阳台等可能有水的地方做防水层，避免漏到楼下或渗到墙体。

谁来做：

- 你：确认防水范围、闭水时间、拍照、联系楼下看漏水。
- 工长/防水师傅：基层处理、防水施工、闭水配合、保护层。

预算卡法：

- 极限目标：3000-5000。
- 两个卫生间都带淋浴，防水不能硬砍。
- 厨房和阳台按实际需要做局部防水。

开工前确认：

- 两个卫生间都按淋浴卫生间做防水。
- 淋浴区墙面防水高度。
- 厨房和阳台是否有实际防水需求。

施工中你看什么：

- 管根、地漏、阴阳角有没有加强。
- 防水是否漏刷、起皮、开裂。
- 防水完成后有没有被踩坏或破坏。

拍照留档：

- 防水施工完成后的地面和墙面。
- 淋浴区墙面高度。
- 管根、地漏、阴阳角加强位置。
- 闭水开始和结束照片。

返工风险：

- 闭水没做就贴砖，后面漏水返工成本最高。
- 淋浴区墙面高度不够，后期墙体返潮。
- 管根没加强，容易从细节处渗漏。

具体步骤：

1. 防水前检查地面和墙角是否清理干净。
2. 让师傅重点处理管根、地漏、阴阳角。
3. 两个卫生间淋浴区墙面至少做到1.8米，预算允许建议做到吊顶底。
4. 非淋浴墙面至少做到30厘米，台盆附近按水 splash 区提高。
5. 防水完成后做闭水24-48小时。
6. 联系楼下或物业看是否漏水。
7. 闭水通过后再做保护层和贴砖。

你要问的话：

- 防水品牌是什么？
- 墙面做多高？
- 两个淋浴区是否都做到1.8米以上？
- 闭水做多久？
- 闭水失败谁负责返工？

可复制话术：

```text
两个卫生间都要保留淋浴，防水不能省。请写清防水品牌、施工遍数、卫生间地面和墙面高度、管根和阴阳角加强、闭水24-48小时。闭水没通过不能贴砖，返工责任也请提前说清。
```

报价单必须写清：

- 防水品牌和型号。
- 防水施工面积。
- 墙面高度。
- 施工遍数。
- 阴阳角、管根加强是否包含。
- 闭水试验是否包含。
- 保护层是否包含。
- 返工责任。

验收：

- 闭水24-48小时楼下无渗漏。
- 防水层无明显漏刷、起皮、开裂。
- 淋浴区墙面高度符合约定。
- 地漏、管根、墙角做了加强。

不要做：

- 不做“只刷一遍就算完”。
- 不做没闭水就贴砖。
- 不做全屋防水这种没必要的增项。

付款/确认节点：

- 防水闭水通过后，再付防水/瓦工前置节点款。

## 2.3 瓦工贴砖

这项是什么：厨房、卫生间、阳台、客餐厅地面贴砖，包含找平、铺贴、坡度、包管、收口等。

谁来做：

- 你：买砖或确认砖、确认铺贴方式、验空鼓和坡度。
- 工长/瓦工：找平、铺贴、包管、收口、地漏坡度。

预算卡法：

- 半包人工辅料目标：12000-20000。
- 瓷砖主材目标：8000-14000。
- 选常规规格，少选小砖、异形砖、斜铺、鱼骨拼。

开工前确认：

- 瓷砖规格、数量、损耗和铺贴方向。
- 厨房、两个卫生间、阳台、客餐厅分别贴什么砖。
- 地漏、门槛石、挡水条是否到场。

施工中你看什么：

- 卫生间地面是否向地漏找坡。
- 砖缝是否明显歪斜。
- 地漏、门槛、阴阳角周边是否收口粗糙。

拍照留档：

- 试铺效果。
- 地漏坡度和地漏位置。
- 包管、门槛石、挡水条。
- 贴砖完成后的整面墙和地面。

返工风险：

- 空鼓过多，后期瓷砖可能脱落或开裂。
- 卫生间坡度不对，洗澡积水。
- 小砖和复杂铺法会拉高人工费。

具体步骤：

1. 贴砖前确定砖的规格、数量、损耗、铺贴方向。
2. 客餐厅用浅色普通砖或浅木纹砖，别追大规格网红砖。
3. 厨房和两个卫生间墙地砖提前送到现场。
4. 让瓦工先试铺一小块，看颜色和方向。
5. 卫生间地面重点看坡度，水要流向地漏。
6. 贴完用空鼓锤或硬物轻敲检查空鼓。
7. 阴阳角、门槛、地漏周边拍照留档。

你要问的话：

- 贴砖人工按平米还是按项目？
- 大砖、小砖、加工砖是否另收费？
- 包管、门槛石、地漏安装、倒角是否包含？
- 空鼓超过多少负责整改？

可复制话术：

```text
瓷砖我会选常规规格，预算紧，不做复杂铺法。请把贴砖面积、人工单价、水泥沙子或瓷砖胶、包管、门槛石安装、地漏安装、倒角、空鼓整改规则写清。卫生间地面坡度要保证排水，贴完我会验空鼓和地漏排水。
```

报价单必须写清：

- 墙砖、地砖铺贴面积。
- 普通砖和大砖人工单价。
- 水泥、沙子、瓷砖胶、背胶是否包含。
- 包立管是否包含。
- 门槛石/挡水条安装是否包含。
- 地漏安装和坡度处理是否包含。
- 空鼓整改标准。

验收：

- 大面积无明显空鼓。
- 砖缝均匀，表面无明显高低差。
- 卫生间和阳台地漏排水顺。
- 墙砖阴阳角顺直。
- 地砖无明显翘角、破损。

不要做：

- 不做小花砖大面积铺贴。
- 不做鱼骨拼、斜铺、复杂拼花。
- 不盲目上大规格岩板砖。
- 不为了好看牺牲卫生间排水坡度。

付款/确认节点：

- 防水闭水通过后贴砖。
- 瓦工验收通过后付瓦工节点款。

## 2.4 墙面基层与乳胶漆

这项是什么：处理墙面基层，刮腻子、打磨、刷底漆和面漆，让全屋墙面干净平整。低配原木风主要靠暖白墙面打底。

快速清单：

| 你要确认 | 默认做法 |
|---|---|
| 是否铲墙 | 让工长现场说明理由 |
| 墙面颜色 | 暖白或白色乳胶漆 |
| 谁施工 | 油工施工，你不自己刷 |
| 重点验收 | 空鼓、裂缝、平整、透底、流坠 |
| 付款 | 验收通过后付油工节点款 |

谁来做：

- 你：确认颜色和品牌，看基层问题，验收墙面。
- 工长/油工：铲墙、修补、找平、挂网、腻子、打磨、刷漆。

预算卡法：

- 目标：8000-13000。
- 全屋乳胶漆最省钱。
- 不做艺术漆、微水泥、墙布、护墙板。

开工前确认：

- 是否铲墙，以及工长给出的理由。
- 墙面裂缝、空鼓、渗水是否先处理。
- 乳胶漆颜色和品牌。

施工中你看什么：

- 腻子遍数是否和报价一致。
- 阴阳角是否明显歪斜。
- 打磨后墙面是否有明显波浪。

拍照留档：

- 铲墙或基层处理前后。
- 裂缝修补和挂网位置。
- 刷漆前确认色卡。
- 刷完后的白天和夜晚墙面。

返工风险：

- 基层没处理好，后期开裂、起皮。
- 深色漆更容易显瑕疵，也更难补。
- 未确认颜色就刷，返工会很麻烦。

具体步骤：

1. 开工前确认墙面是否需要铲墙，让工长现场报“铲墙/不铲墙”的理由。
2. 让报价单写清楚：铲墙、修补、找平、挂网、腻子几遍、打磨、底漆、面漆分别是否包含。
3. 你自己只买或确认乳胶漆颜色和品牌，不自己刷。
4. 油工进场前，确认墙面空鼓、裂缝、渗水有没有处理。
5. 腻子完成后看墙面平整度和阴阳角。
6. 刷漆前确认颜色，建议全屋暖白。
7. 刷完后白天和晚上各看一次，有透底、流坠、开裂就让整改。
8. 验收通过后再付油工节点款。

你要问的话：

- 是否铲墙？为什么？
- 腻子几遍？
- 是否含底漆和两遍面漆？
- 裂缝和阴阳角怎么处理？
- 乳胶漆品牌、型号、用量写不写？

可复制话术：

```text
墙面我做低配原木风，默认暖白乳胶漆，不做艺术漆和墙布。请帮我写清是否铲墙、裂缝修补、找平、挂网、腻子几遍、打磨、底漆、面漆、乳胶漆品牌型号和面积。刷完我会白天晚上各看一次，有透底、流坠、开裂、阴阳角明显歪斜请整改。
```

报价单必须写清：

- 是否铲墙。
- 是否修补裂缝。
- 是否挂网。
- 石膏找平是否包含。
- 腻子几遍。
- 是否含打磨。
- 是否含底漆。
- 是否含面漆。
- 乳胶漆品牌、型号、用量。
- 单价、面积、总价。

验收：

- 墙面无明显裂缝、起皮、透底。
- 侧光看没有特别明显波浪。
- 阴阳角基本顺直。
- 开关、门套、踢脚线周边收口干净。
- 颜色和确认色一致。

不要做：

- 不做艺术漆。
- 不做微水泥。
- 不做墙布。
- 不做大面积护墙板。
- 不用深色墙面增加修补难度。

付款/确认节点：

- 腻子前确认基层处理范围。
- 刷漆前确认颜色。
- 墙面验收通过后付油工节点款。

## 2.5 地面找平

这项是什么：把地面处理到能铺砖或铺地板的平整状态。

谁来做：

- 你：确认哪些区域找平、铺砖还是铺地板。
- 工长/瓦工：找平施工。
- 地板商家：安装前复测地面平整度。

预算卡法：

- 目标：3000-8000，按实际面积看。
- 卧室铺强化复合地板时，地面不平会影响后期异响。

开工前确认：

- 哪些区域铺砖，哪些区域铺地板。
- 卧室地板商家对平整度的要求。
- 找平厚度是否影响门槛和门洞。

施工中你看什么：

- 找平区域是否和报价一致。
- 表面是否大面积开裂、起砂。
- 是否预留足够养护时间。

拍照留档：

- 找平前地面。
- 找平完成后的整体地面。
- 地板商家复测结果。

返工风险：

- 地面不平会导致地板异响、起翘。
- 找平过厚可能影响门和地面高差。

具体步骤：

1. 开工前定客餐厅铺砖、卧室铺强化复合地板。
2. 瓦工阶段确认卧室地面是否需要找平。
3. 地板安装前让商家复测地面平整。
4. 不平的地方先处理，再装地板。

你要问的话：

- 哪些区域需要找平？
- 找平厚度多少？
- 找平后多久能铺地板？
- 找平费用是否包含在半包？

可复制话术：

```text
卧室我要铺强化复合地板，请先确认地面平整度。需要找平的区域请写清面积、厚度、单价和总价。地板安装前如果地面不平导致异响，请提前处理，不要装完再说。
```

报价单必须写清：

- 找平区域。
- 面积。
- 厚度。
- 单价。
- 材料和人工是否包含。
- 是否含养护。

验收：

- 地面无明显高低差。
- 找平层无大面积开裂、空鼓。
- 地板安装前商家认可可安装。

不要做：

- 不为了省找平导致地板后期大面积异响。
- 不做没必要的全屋厚找平。

付款/确认节点：

- 找平完成并确认可进入下一道工序后付款。

## 2.6 厨卫吊顶

这项是什么：厨房和两个卫生间做铝扣板吊顶，遮管线、装灯、装浴霸和排风。

谁来做：

- 你：选基础铝扣板颜色和浴霸/灯。
- 商家/安装师傅：安装吊顶、边条、检修口。
- 工长：协调管线和收口。

预算卡法：

- 目标：2500-5000。
- 默认只做厨卫吊顶，客餐厅和卧室不吊顶；如果最终保留中央空调，中央空调相关局部吊顶另算。

中央空调例外：

- 如果最终保留小米双风轮6匹1拖5，客餐厅和卧室可能需要局部吊顶，不再是纯“只做厨卫吊顶”。
- 中央空调吊顶要单独报价，不要混在厨卫铝扣板里。
- 原则是“能少吊就少吊”：优先边吊、过道吊、局部包管，不做满吊和平顶大造型。
- 所有回风口、出风口、检修口位置要由空调商家、工长、木工/吊顶方三方现场确认。

开工前确认：

- 厨房和两个卫生间吊顶面积。
- 浴霸、灯、排风、检修口位置。
- 铝扣板颜色和规格。

施工中你看什么：

- 龙骨和边条是否安装平整。
- 检修口有没有保留。
- 浴霸、排风、灯位有没有被遮挡。

拍照留档：

- 吊顶前管线和排风位置。
- 龙骨安装过程。
- 吊顶完成后的整体效果。

返工风险：

- 没留检修口，后期维修麻烦。
- 浴霸或排风位置不对，使用体验差。
- 边条收口粗糙，会显得很廉价。

具体步骤：

1. 瓦工结束后测量厨房和两个卫生间吊顶面积。
2. 选白色或浅色普通铝扣板。
3. 两个卫生间都需要浴霸或排风，预算紧可选基础款。
4. 安装前确认烟道、排风、检修口位置。
5. 安装后检查平整、边条、灯和浴霸是否正常。
6. 如果保留中央空调，先拿空调布置图，再让吊顶方按图报价，不要先做吊顶再想空调。

你要问的话：

- 铝扣板多少钱一平？
- 边条、龙骨、安装是否包含？
- 浴霸安装是否另收费？
- 检修口是否保留？

可复制话术：

```text
厨卫吊顶我只要基础白色铝扣板，不做复杂造型。请写清铝扣板单价、面积、龙骨、边条、安装、检修口、浴霸/灯安装是否包含。两个卫生间都要能装浴霸或排风。
如果我最终保留小米双风轮6匹1拖5中央空调，请把中央空调相关吊顶单独报价：哪些房间需要吊顶、吊多宽、吊多高、出风口回风口检修口在哪里、是否影响层高。不要把中央空调吊顶混进厨卫吊顶报价里。
```

报价单必须写清：

- 铝扣板品牌或规格。
- 单价和面积。
- 龙骨、边条是否包含。
- 安装费是否包含。
- 检修口是否包含。
- 灯具、浴霸安装是否包含。
- 中央空调吊顶如果发生，要单独写区域、面积、长度、高度、风口和检修口。

验收：

- 吊顶平整。
- 边条收口整齐。
- 浴霸、灯、排风能正常使用。
- 检修口位置合理。

不要做：

- 不做客餐厅复杂吊顶；如果保留中央空调，只接受必要局部吊顶。
- 不做复杂厨卫吊顶造型。
- 不买高价蜂窝大板。
- 不为了中央空调做满屋复杂吊顶。

付款/确认节点：

- 安装完成、灯和浴霸测试正常后付安装尾款。
