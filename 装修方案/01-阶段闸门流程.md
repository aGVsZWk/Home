# 阶段闸门流程

这一部分按时间顺序走。每个阶段没过“验收出口”，不要进入下一笔大付款。

## 1.1 阶段1：准备与量房

这个阶段的目标：把需求固定下来，让3-5家按同一口径报价。

你要做的事：

- 准备户型图、收房资料、物业装修要求。
- 拍毛坯房照片：厨房、两个卫生间、阳台、强弱电箱、窗户、墙面裂缝。
- 给所有工长同一段需求，不要每家说法不同。
- 记录每家量房时说的增项风险。

你要找谁：

- 3-5个工长或半包装修公司。
- 1-2个橱柜/定制商家。

必须先定的东西：

- 厨房和两个卫生间位置不大改。
- 两个卫生间都带淋浴。
- 洗衣机默认放阳台。
- 主卧自住、次卧1老人住、次卧2书房为主。

报价/合同要卡什么：

- 报价必须有项目、单价、面积、辅材品牌、施工范围。
- 水电算法必须写清，是按点位、按米数，还是一口价。
- 垃圾清运、材料上楼、成品保护、开孔、包管是否包含。

验收出口：

- 你手里至少有3份可对比报价。
- 每份报价不是一口总价，而是明细报价。
- 每家都说明了哪些项目可能加钱。

没通过不能付款：

- 没有明细报价不能交定金。
- 对方不愿写辅材品牌不能交定金。
- 对方催你当天签，不要交定金。

## 1.2 阶段2：报价与签约

这个阶段的目标：选一个报价清楚、愿意写明增项规则的人。

你要做的事：

- 把报价放到同一个表里横向比较。
- 重点看漏项，不只看总价。
- 让对方把口头承诺写到合同或报价附件。

你要找谁：

- 最终候选的工长/装修公司。
- 如有必要，找懂装修的朋友帮你看报价。

必须先定的东西：

- 付款节点。
- 增项确认规则。
- 辅材品牌。
- 工期。
- 质保时间。

报价/合同要卡什么：

```text
增项必须提前写明项目、单价、数量、原因，经我书面确认后才能施工；未经确认的增项我不付款。
水电完工必须拍照留档并验收后再封槽。
卫生间防水必须闭水24-48小时，确认不漏后再贴砖。
尾款保留5%-10%，竣工整改完成后再付。
```

验收出口：

- 合同、报价、付款节点、增项规则都写清。
- 辅材品牌型号写清。
- 你知道哪些主材自己买，哪些辅材半包含。

没通过不能付款：

- 合同只写“按实际结算”但没有单价，不能签。
- 报价里没有防水、找平、垃圾清运、材料上楼，不能签。
- 付款一开始要50%以上，不建议签。

## 1.3 阶段3：开工交底

这个阶段的目标：把水位、电位、灯位、柜子、门、洁具尺寸提前说清，减少返工。

你要做的事：

- 带户型图到现场。
- 和工长逐个空间走一遍。
- 用胶带或记号笔标插座、开关、灯位、水位。
- 拍视频记录交底结果。

你要找谁：

- 工长。
- 水电师傅。
- 橱柜商家。
- 如果已确定洁具和电器，也让商家给尺寸图。

必须先定的东西：

- 冰箱放厨房还是餐厅边，默认先按厨房/餐厅边就近预留。
- 洗衣机放阳台。
- 两个卫生间都有花洒、马桶、浴室柜。
- 厨房预留洗碗机、净水器、小厨电插座，但不默认购买。
- 开放式厨房按硬目标核验：物业、燃气、承重墙、烟道、门洞、油烟和拆改报价。
- 导台/吧台、餐桌、冰箱、餐厨通道关系要现场画出来。
- 老人房按1.8米床优先预留，床头两侧留插座和开关。
- 书房按带门独立安静电脑房优先，书桌插座和网口不能被沙发床挤掉。
- 两辆公路车、椭圆机、猫设备、清洁设备要现场标出默认外露位置。
- 阳台按洗衣机、烘干机、分桶洗衣机预留，但不做洗手台。

报价/合同要卡什么：

- 开工交底确认的水位、电位、灯位要拍照，后续施工按这个执行。
- 橱柜商家提供的厨房水电建议要给工长确认，避免后面说“没预留要加钱”。
- 只预留的洗碗机、净水器、小厨电、洗烘套装本体、分桶洗衣机本体、电视影音本体、扫地机器人上下水、3D打印机独立空间，报价里不能算成现在购买。

验收出口：

- 水电点位图或现场标记拍照保存。
- 橱柜水电建议已确认。
- 工长知道哪些是现在做，哪些只是预留。

没通过不能付款：

- 水电没有定位清楚，不要开槽。
- 厨房橱柜没有基本方案，不要随便定水位。
- 卫生间花洒、马桶、浴室柜位置没核对，不要改管。

## 1.4 阶段4：拆改与水电

这个阶段的目标：少拆少改，做好隐蔽工程，拍照留档。

你要做的事：

- 确认只拆非承重、非结构部分。
- 水电施工前再核对一遍点位。
- 水电完工后拍照、录像、保存走向。
- 让工长做水管打压、电路通断检查。

你要找谁：

- 工长。
- 水电师傅。
- 必要时问物业哪些墙不能动。

必须先定的东西：

- 开关插座位置。
- 厨房水槽、燃气灶、烟机、冰箱、净水器预留位。
- 两个卫生间马桶、花洒、浴室柜、浴霸位置。
- 独立书房电脑、网口、摄影/无人机/3D打印设备充电位。
- 电视墙85寸电视、回音壁、低音炮、后环绕电源和线管。
- 猫砂盆、自动喂食机、饮水机、扫地机器人、洗地机位置。
- 阳台洗衣机、烘干机、分桶洗衣机上下水、插座、地漏；无阳台洗手台。

报价/合同要卡什么：

- 水电增项必须按已确认点位或米数计算，不能施工完再报一个总数。
- 开槽、封槽、水管打压、强弱电点位、阳台洗衣机位都要写清是否包含。
- 厨卫位置不大改，任何大移位都要先说明原因、费用和风险；开放式厨房涉及拆改、燃气或烟道的，必须单独确认合规和报价。

验收出口：

- 强弱电分开，线管固定，横平竖直不乱绕。
- 水管打压合格。
- 厨卫阳台水电位置和你确认的一致。
- 所有隐蔽工程拍照留档。

没通过不能付款：

- 没有水管打压记录，不付水电节点款。
- 点位数量和报价不一致，先核对再付款。
- 未经确认产生大额水电增项，先谈清再付款。

## 1.5 阶段5：防水与瓦工

这个阶段的目标：两个卫生间都能洗澡，厨房阳台稳定耐用，瓷砖别空鼓。

你要做的事：

- 防水前确认基层干净、管根和阴阳角加强。
- 两个卫生间都做闭水试验。
- 贴砖前确认瓷砖规格、铺贴方向、损耗。
- 瓦工完工后敲空鼓、看坡度、看地漏排水。

你要找谁：

- 工长。
- 防水师傅。
- 瓦工。
- 楼下邻居或物业配合看闭水。

必须先定的东西：

- 厨房墙砖、地砖。
- 两个卫生间墙砖、地砖。
- 阳台地砖。
- 地漏款式和位置。
- 门槛石或挡水条是否做。

报价/合同要卡什么：

- 防水品牌、面积、高度、遍数、闭水试验必须写清。
- 贴砖面积、人工单价、辅材、包管、地漏坡度、空鼓整改标准必须写清。
- 两个卫生间都带淋浴，不能只按一个淋浴区报价。

验收出口：

- 卫生间闭水24-48小时无漏水。
- 淋浴区坡度能把水导向地漏。
- 砖面无明显空鼓、翘角、错缝。
- 阴阳角顺直。

没通过不能付款：

- 闭水没做完，不贴砖。
- 地漏排水不顺，不付瓦工节点款。
- 空鼓明显，先整改。

## 1.6 阶段6：油工与基础安装

这个阶段的目标：墙面平整干净，厨卫吊顶、门、地板等基础硬装收口。

你要做的事：

- 油工进场前看墙面空鼓、裂缝、渗水。
- 刷漆前确认颜色，默认暖白。
- 白天和晚上各看一次墙面效果。
- 安装门和地板前确认地面平整、门洞尺寸。

你要找谁：

- 油工。
- 工长。
- 门商家。
- 地板商家。
- 厨卫吊顶商家或工长安排的安装师傅。

必须先定的东西：

- 乳胶漆颜色和品牌。
- 室内门颜色，建议普通木色或白色。
- 卧室地板颜色，建议浅木色。
- 厨卫铝扣板颜色，建议白色或浅色。

报价/合同要卡什么：

- 墙面必须写清铲墙、修补、挂网、腻子、底漆、面漆分别是否包含。
- 室内门、地板、厨卫吊顶要写清测量、安装、上楼、收口是否包含。
- 乳胶漆颜色和品牌确认后再施工，避免刷错后扯皮。

验收出口：

- 墙面无明显透底、流坠、开裂。
- 阴阳角基本顺直。
- 门开关顺畅。
- 地板无明显起翘、异响。
- 厨卫吊顶平整，检修口保留。

没通过不能付款：

- 墙面问题没有整改，不付油工节点款。
- 门装歪、关不上，不付安装尾款。
- 地板大面积异响或起拱，先整改。

## 1.7 阶段7：柜子与洁具安装

这个阶段的目标：刚需柜、洁具、灯具、开关插座安装到能住。

你要做的事：

- 橱柜安装前确认台面、水槽、灶具、烟机尺寸。
- 衣柜和鞋柜安装前确认板材、柜门颜色、五金数量。
- 洁具安装后逐个试水、试排水。
- 灯具开关插座装完逐个测试。

你要找谁：

- 橱柜商家。
- 定制柜商家。
- 洁具安装师傅。
- 灯具安装师傅。
- 工长协调收口。

必须先定的东西：

- 橱柜地柜、吊柜长度。
- 主卧衣柜尺寸。
- 玄关鞋柜尺寸。
- 两个卫生间马桶、花洒、浴室柜、地漏。
- 各房间灯具和开关插座面板。

报价/合同要卡什么：

- 柜子要按单个柜体报价，不接受“全屋定制套餐”混在一起。
- 洁具、灯具、开关插座要写清安装费、辅材费、上楼费。
- 橱柜、衣柜、鞋柜都要写清五金、封板、抽屉、开孔是否另算。

验收出口：

- 柜门开关顺畅，缝隙基本一致。
- 台面无明显破损，水槽不漏水。
- 马桶冲水正常，花洒冷热水正常。
- 插座通电，开关控制对应灯。

没通过不能付款：

- 柜子尺寸错误、门板破损，不付尾款。
- 洁具漏水，不付安装尾款。
- 开关插座错位或不通电，先整改。

## 1.8 阶段8：竣工验收与入住

这个阶段的目标：列整改清单，整改完再付尾款。

你要做的事：

- 全屋逐项检查，拍照编号。
- 把问题发给工长，写清整改期限。
- 尾款留5%-10%，整改完再付。
- 开窗通风，家具家电慢慢补。

你要找谁：

- 工长。
- 各安装商家。
- 必要时找第三方验房或懂装修的人陪看。

必须先定的东西：

- 所有整改问题要形成清单。
- 尾款比例按合同保留。
- 保修联系人和保修范围要确认。

报价/合同要卡什么：

- 尾款必须和整改完成绑定。
- 保修范围、保修期限、售后联系人要写清。
- 各商家的安装尾款要等试水、试电、试开关通过后再付。

验收出口：

- 墙地面、门窗、灯具、插座、洁具、下水、柜子、地漏都检查过。
- 整改问题全部处理。
- 保修范围和联系方式确认。

没通过不能付款：

- 有漏水、跳闸、空鼓、柜子严重问题，不能结清尾款。
- 对方不愿写保修，不建议结清。
