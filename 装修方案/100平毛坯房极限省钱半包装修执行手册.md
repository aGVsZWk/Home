# 100平毛坯房极限省钱半包装修执行手册

适用对象：石家庄，毛坯房，三室两厅两卫，建筑面积约129平，按套内约100平做预算控制。  
你的角色：唯一业主项目经理，不亲自施工。你负责确认、采购、沟通、拍照、验收、控款；水电、防水、瓦工、吊顶、燃气等专业工作由工长、工人、商家或安装师傅做。

核心路线：**半包 + 自己买基础主材 + 只做刚需柜 + 低配原木风 + 家具家电后补**。

核心原则：**先能住，再好看；先保隐蔽工程，再保风格；先卡预算，再谈升级**。
